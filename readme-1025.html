> 현재 Runtime 상태 (2026-10-18 갱신): api는 RT-08(a)의 app factory·HTTP envelope·
> health를 구현했다. 실제 Search adapter 연결은 후속 작업이다.

## 무엇을 하고, 무엇을 하지 않는가
