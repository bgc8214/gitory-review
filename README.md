# Gitory — 심사 대비 분석 자료

멘토 심사 100점 기준으로 현재 구현 상태를 진단하고, 보완 방향을 정리한 자료입니다.

**→ https://bgc8214.github.io/gitory-review/**

## 구성

| | 문서 | 내용 |
|---|---|---|
| ★ | 회의 결정사항 | 10/25 회의 7가지를 배점·제출물 요구사항과 대조 · 16일 실행 순서 |
| 01 | 심사 100점 항목별 | 10항목 각각의 현재 상태(파일 증거)와 보완 시 기대 점수 |
| 02 | 보완 계획 | 항목별 액션 + 제출물 6종을 "꼭 포함할 내용" 단위로 대조 |
| 03 | Agentic 쉽게 | 전문 용어 없이 — 왜 점수가 낮고 뭘 하면 되나 |
| 04 | Agentic 설계 | 도구·루프·구현 4단계 PR 분할 (기술) |
| 05 | 업계 사례 | AI 에이전트 제품 10개의 과정 표시 방식 + 계측 |
| 06 | README 다시 쓰기 | 벤치마크 + 초안 |

## 작성 기준

- 2026-10-25 운영 서비스 전 기능을 실제로 실행하고, `origin/develop` 코드를 대조
- 점수는 **배점표 기준 추정치** — 실제 채점자가 다르게 볼 수 있음
- 다른 팀 사례는 **익명(A팀·B팀…)** 으로만 기재
- 초기 판단이 틀렸던 부분은 지우지 않고 각 문서에 **정정 표기**로 남김
